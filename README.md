📌 Project Overview
This project is a fully functional Student Learning Portal built using HTML, CSS, and JavaScript. It demonstrates key concepts required for the module, including event‑driven programming, interoperability using external APIs, virtual identity using localStorage, responsive UI design, multi‑page navigation, GitHub version control, and GitHub Pages deployment. The portal includes a login system, a dashboard, and multiple functional pages such as Courses, Assignments, and Support.
